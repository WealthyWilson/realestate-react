# realestate-react

A React project scaffolded with Vite. Use this repository to convert your existing HTML website into a modern React app.

---

## ✅ Quick Start

### 1) Install dependencies

```bash
npm install
```

### 2) Run the dev server

```bash
npm run dev
```

Open http://localhost:5173 in your browser.

---

## 🔁 Converting your HTML to React

1. **Identify your existing HTML structure** (e.g., `index.html`, `about.html`, etc.).
2. **Create React components** in `src/` and paste your HTML markup into `src/App.jsx` (or additional components).
3. **Convert static assets**:
   - Put images (PNG/JPG/SVG) under `src/assets/` and import them in components.
   - For global styles, put CSS in `src/App.css` and import it from `src/App.jsx`.
4. **Add routing** (optional): install `react-router-dom` if you want multiple pages.
